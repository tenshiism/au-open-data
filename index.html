Graham Jaroslow · Melbourne · Python, SQL, data visualisation · GitHub

Built with a Python/pandas pipeline over the ABS Data API (CPI_Q, WPI, ERP_Q) and BoM climate time series, rendered with Chart.js. BoM has no separate ACT series, so ACT uses NSW climate data.
